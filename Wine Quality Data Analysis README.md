Wine Quality Data Analysis
Overview

This project uses Python to analyze a dataset of red wine characteristics and explore relationships between wine quality, alcohol concentration, and pH.

The project was originally completed as part of an introductory programming and data analysis course.

Objectives
Load and examine a dataset using Pandas
Calculate basic descriptive statistics
Compare alcohol and pH across different wine quality ratings
Create visualizations to identify patterns in the data
Interpret the results and identify potential areas for further analysis
Tools & Technologies
Python
Jupyter Notebook
Pandas
Matplotlib
Seaborn
Analysis

The analysis examines:

Mean, median, minimum, maximum, standard deviation, and range for alcohol and pH
Alcohol and pH statistics across wine quality ratings
The relationship between alcohol and pH
The distribution of alcohol and pH values
The distribution of alcohol across different wine quality ratings
Key Findings

The analysis found that higher-rated wines in this dataset generally had higher average alcohol concentrations. Wines rated 7 and 8 had average alcohol concentrations of 11.47% and 12.09%, respectively, compared with 9.96% for wines rated 3 and 10.27% for wines rated 4.

The pH values were relatively similar across quality levels, with average values ranging from 3.27 to 3.40.

The analysis suggests that alcohol concentration may have a relationship with wine quality, while pH showed less variation across the different quality categories.

Future Analysis

Additional variables in the dataset could be analyzed to investigate whether other characteristics have stronger relationships with wine quality. Potential variables include fixed acidity, volatile acidity, citric acid, residual sugar, chlorides, sulfur dioxide, density, and sulphates.
